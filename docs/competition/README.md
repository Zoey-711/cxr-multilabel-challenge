# 比赛规则原件与执行核对

本目录保存主办方 2026-10-23 发布的[《比赛参赛规则》原件](official_rules_20261023.pdf)。来源：[主办方 PDF](https://ncccu2026.oss-cn-zhangjiakou.aliyuncs.com/ueditor/20261023/aa80bececc2ee40e69cde5f8f2a0eaec.pdf)。下载于 2026-10-27；文件 544,529 字节，SHA-256：`ff6aa3adbfd3d000194253055a93dbce8a140031c8432f892046a49de8136fb6`。如主办方后续更新，以更新后的原件为准。

下面只列与本仓库实验和部署直接相关的条款，具体表述及提交材料见 PDF：

- 第 1–2 条：预训练骨干须来自允许的非医学领域公开权重，许可证须允许赛事使用及再分发；训练只使用赛方提供的训练数据。提交材料须包含权重来源、许可证全文、上游数据说明及 SHA-256。
- 第 3 条：若将官方验证集并入训练，它不能再用于早停、checkpoint 选择或参数调整。本仓库的折训练协议将官方 Val 留作验证；报告须注明它已被反复使用，不能视为新的独立测试集。
- 第 5–6 条：无标签 Test 图像不能用于训练、伪标签、统计量拟合或模型选择。测试时使用固定权重与 `eval` 模式；允许固定的 TTA 和模型集成。
- 第 7 条：主办方指定环境，5 张预热图，100 张计时图，`batch=1` 串行连续 3 轮；从读图到写出最终预测结果计时，包含预处理和后处理。先对每张图的 3 轮取均值，再对 100 张取均值。平均耗时上限 **≤100 ms**；`cost.py` 必须调用与 `predict.py` 相同的推理函数和模型加载逻辑，输出须与提交 CSV 一致。4060/4090 测速不能证明目标环境合规。
- 第 8 条：最终实际加载的权重去重后，加上推理所需配置、统计量、类别表、引擎等文件，**解压后合计 ≤500 MB**。未加载的训练断点和其他格式权重不计入。不能用压缩包大小代替。
- 第 9–10 条及附录 A：保留提交、撤销和最终材料要求；提交前核对 `cost.py`、`predict.py`、模型文件、依赖、许可证、来源说明和文件清单。此分支不会自动向比赛平台提交。

历史代码快照 [`research_archive/local_20261026/docs/rules.md`](../../research_archive/local_20261026/docs/rules.md) 是旧阶段记录，其中关于“压缩后模型大小”等文字与本 PDF 不一致；它仅作历史溯源，不能代替本原件。
