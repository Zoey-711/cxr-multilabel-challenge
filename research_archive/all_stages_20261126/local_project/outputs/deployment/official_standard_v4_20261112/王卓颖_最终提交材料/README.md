# 王卓颖：最终提交材料（官方标准修订V4）

本包申报历史78.81六模型，不含LR_HIGH。model/完整运行源码、权重、T4引擎与84.46ms参考记录一致；根目录cost.py为新终端适配，不将84.46ms冒充新版cost实测。官方决定最终测速和一致性验收结论。

## 运行
使用官方compete:3.0镜像的预装框架，不自动升级或重装。Python3.12、PyTorch2.10.0 CUDA12.8/cuDNN9、TensorRT10.9.0.34、ORT GPU1.26.0。三处requirements说明一致。
```bash
python cost.py submission.csv pictures_100 pictures_5
```
仅三个位置参数。5张独立预热，100张图片batch=1串行、连续3轮；计入读取、预处理、前向、后处理、预测终端写出/flush及CUDA同步，先每图三轮平均再总体平均。模型加载/首次初始化/预热不计时。只向终端输出，不创建结果文件（依据用户转述的额外执行约定，非声称PDF明确禁止写文件）。

完整对应时打印官方示例[CONCLUSION]，使用实际耗时、不一致图片数及FP16/FP32混合精度。对每轮结果与传入CSV比较，判定或排序改变、最大概率差超过1e-3均计为不一致；同图片跨轮失败只计一次。
三轮非零浮点差仅记录，不再以逐位相同为额外通过门槛。CSV只校验键、类别、概率，文件SHA仅记录来源，不因行序或换行改变提前拒绝。

## 仍需明确的核验范围
官方未规定必须提供完整Study。任意100张均正常完成单图测速；但历史CSV为完整Study Mean，缺少该Study其他影像时无法证明单图与完整平均一致。未核验数量单独列出，不判为通过或假造不一致0张；此时结论明确未完成100张一致性验收，返回非零验收状态。该状态是程序如实报告，不是官方豁免。
0.5 Gate来自历史内部审计约定，并非PDF明确给定的阈值；十类排序同值按类别ID稳定处理。未根据测试调整；若官方定义不同需先明确，不擅改阈值。
不得缓存缺失影像预测、用历史CSV回填预测或更改单图/Study融合来通过核验。
