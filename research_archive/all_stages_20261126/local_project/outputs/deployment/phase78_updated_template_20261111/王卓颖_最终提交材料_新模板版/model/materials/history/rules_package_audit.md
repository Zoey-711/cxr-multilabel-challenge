## 逐项结果

| 规则 | 实际证据 | 状态 |
|---|---|---|
| 第6条固定参数、eval、无测试时训练 | PyTorch 权重按 eval 加载，代码只有前向及固定 Study Mean；TensorRT 引擎仍需在目标机加载检查 | 实现通过，目标机待验 |
| 第7条 batch=1、5张预热、100张×3轮，端到端计时 | `cost.py` 实现逐图前向、文件读取、预测写出及 CUDA 同步；未在 T4 运行该六模型路径 | T4 待验 |
| 第7条 `cost.py` 与 `predict.py` 共用逻辑 | 本地函数对象相同 | 通过 |
| 补充说明第九部分的预测一致性 | 4060 的纯 PyTorch batch=1 全 Test 有 10/1414 Study 排序变化；T4 混合引擎全 Test 尚未执行 | **未通过历史提交验收** |
| 第8条解压后推理文件≤500MB | 六模型实际加载文件及必要配置为 392,800,139 字节；36个包内文件哈希通过 | 大小通过 |
| 第1、10条和附录A的开源权重、许可证、数据来源与材料清单 | 包内没有许可证全文，也没有已填写的声明清单；预训练原始权重 SHA/链接需逐一附证 | 材料不齐 |

`cost.py` 比较的是完整 Study 的聚合概率。若主办方指定的100张图片仅覆盖某些 Study 的一部分，当前工具会给出 `UNVERIFIED_PARTIAL_STUDY`，不能完成补充说明要求的100张逐样本一致性认定。当前二值判定核验使用0.5阈值，而官方 `Pred_Label/Gate` 的具体判定定义未在包内证明。`cost.py` 还需要单独的100张索引文件；规则提供的三位置参数命令只是参考格式，但现有接口未按该命令直接运行。

新版包的 README 仍写着旧版压缩包名 `e08_s17_t4_batch1_candidate_20261110.tar.gz`，末尾新增中文段落含乱码。正确包名是 `e08_s17_t4_batch1_full_audit_v2_20261110.tar.gz`。该问题影响交付可用性，应在正式交付前修正并重新哈希。

## 本地测速口径

`outputs/analysis/e08_s17_phase65_acceleration_20261110/final_entry_cost/report.json` 的**六模型纯 PyTorch FP16 CUDA Graph** 在 RTX 4060 Laptop、固定 Val 100图、5张预热、3轮、batch=1 的端到端均值为 **53.791595 ms**，P50 **53.841300 ms**，P95 **60.490330 ms**。这不是当前包的混合 PyTorch/TensorRT 入口；后者在 Windows 缺少 TensorRT，**没有本地完整六模型测速值**。原 Phase65 的五模型 T4 均值 76.10ms 也不能迁移到六模型。

此包要成为正式候选，必须先在目标 T4 上完成 2218张 Test 全量复算、1414 Study 与历史提交的逐项一致性，以及主办方100张样本的真实计时和逐样本核对；随后补齐模型来源、预训练许可证全文、原始权重哈希及声明清单。不能根据本地53.79ms断言当前混合入口在 T4 上≤100ms。
