# H50-KD 外层 Fold1 教师重建条件

H50-BASE 只使用真实标签。原 E17 完整五折 OOF 不满足这里的外层隔离：对学生训练 Fold2–5 的部分患者，原 OOF 教师曾使用 Fold1 患者训练。故 H50-KD 保持 BLOCKED。

若要评估无外层 Fold1 信息的蒸馏学生，先把外层 Fold1 全体患者从**所有**教师训练、预处理统计量计算、教师调参和 checkpoint 选择中排除。然后只在剩余 Fold2–5 患者内构造患者级内层四折。每个内层教师仅在其他三个内折训练，预测其未见过的内折患者。为复现冻结的 D/C/S 教师融合，每个内折训练 DenseNet、ConvNeXt、Swin 各一项，共 4×3=12 项教师训练；逐 Study 核对来源患者与训练患者不相交后，按 0.25/0.25/0.50 生成学生训练软标签。教师的 ImageNet 初始化和其他协议须固定并记录。

这些新教师结果不能与原 E17 完整五折 OOF 混称同一模型。构造完成后才可训练 H50-KD，并在同一个外层 Fold1 集合上与 H50-BASE 配对比较。H50-KD 的训练集预测仍不属于独立 OOF。
