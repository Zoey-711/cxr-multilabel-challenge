# E08 固定少量融合比例评估

本次只读取已冻结的 Val 概率及真实标签，在完全对齐的859 Study、228患者上进行CPU复算。原版五模型公式复现最大误差为0；原版和ONNX FP32的AUC均复现已存记录。来源文件SHA核验通过。未读取Test概率、未训练、未生成Submission、未修改冻结产物。

## 两个E08版本相混

公式为 `(1-w) * 原版E08 + w * ONNX_FP32_E08`。预先固定w为0.25、0.50、0.75，其Val AUC分别为0.811674422、0.811709848、0.811720979，均未超过ONNX单独的0.811733156。两版逐类Pearson相关系数为0.999977712–0.999996872。

没有证据支持同时部署两个引擎进行混合。现有两份完整部署包合计555,230,904字节，简单拼接超过500,000,000字节；逐图需执行两套五模型前向。共享存储或统一混合精度计算需另行实现及验收，不能假定只算一份权重就合规。

本次有限候选中最高的是B01/B02/B03/M02/N01_EMA = **0.10/0.10/0.10/0.30/0.40**。相对原版差+0.000532989，2000次患者级配对Bootstrap 95%区间为[-0.000662304,+0.001515962]；全部2000次有效，seed=42。相对ONNX单独的差+0.000468479，区间[-0.000718821,+0.001422852]。两者均跨0。

该比例7类上升、3类下降。类别1提升0.003143713，类别4下降0.000083662，类别8下降0.000224589；最大下降为类别3的0.000775443。保留5模型，权重体积和前向数量不因调比例而减少，T4_UNVERIFIED。

## 判断

- 可以获得更高的开发Val AUC，但尚无可靠证据证明隐藏测试提分。
- 0.10/0.10/0.10/0.30/0.40仅作为探索性参数记录，不是全局最优，也不能直接替换77.75的冻结基线。
- 官方Val被多轮使用，本次同时检查多个方案；区间未校正多重比较，也未消除反复模型选择偏差。
- ONNX各子模型独立Val概率不在本次已核验输入中，因此没有对ONNX内部新比例宣称实测AUC；不能用原版的0.812201635替代其结果。
- 若继续，应先冻结唯一待确认比例，取得独立患者验证或合法对应OOF证据，再决定是否生成该入口的独立Test Submission。没有新的证据前保留E08原版为官方基准，不扩大比例搜索。

完整参数、区间和逐类指标见comparison.csv、per_class_auc.csv，来源哈希与方法见audit.json。Bootstrap采用患者重复次数加权的精确AUC；每个方案的前三个重采样均与显式复制Study后的原项目排序AUC实现核对，容差1e-12通过。
