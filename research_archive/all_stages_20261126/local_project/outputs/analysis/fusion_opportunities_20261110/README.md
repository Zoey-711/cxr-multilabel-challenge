## 统计方法

每项10类Study AUROC算术平均；228名患者配对重采样2000次，seed20261110，各候选使用同一批重采样。任一类别缺正或负样本则丢弃整次重复，不补抽。保留普通95%百分位区间，并对全部382项使用中心化标准化bootstrap maxT给出近似单侧家族校正p值和同时下界。

maxT只处理当前382项比较，不消除历史反复查看官方Val、模型早停和过去筛选造成的偏差；区间也不包含训练种子不确定性。E08不存在合法同协议Train OOF，本轮不伪造任何融合的独立OOF结果。单模型OOF的可用性不能自动赋予E08混合结果OOF性质。
